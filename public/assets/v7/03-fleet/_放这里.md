# 03-fleet — 设备资源（三张卡片）

把照片按下面的文件名放进本文件夹（文件名必须一致，只有内容可变）：

| 文件名 | 画什么 | 规格 |
|---|---|---|
| `fleet-wind-truck.jpg` | 风机运输特种车，侧面或 3/4 角，能看出车长 | 1680×1120（3:2）／≤300KB |
| `fleet-blade-lifter.jpg` | 叶片举升车，举升状态最好，叶片与坡度关系要看得清 | 1680×1120（3:2）／≤300KB |
| `fleet-support.jpg` | 配套资源：低平板/多轴轴线车/吊车协同，或车队编组 | 1680×1120（3:2）／≤300KB |

通用要求：横构图、白天自然光、无水印、不要车牌特写、四周留 5–8% 余量；给原图不要先压缩。

压成规格：
```bash
python scripts/optimize-images.py <原图> --as hero --out v7/03-fleet/<文件名去掉.jpg>
# 全幅图（2000×1200）用 --as hero；卡片图（1680×1120）用 --as card
```

放好后在此目录跑 `python scripts/check-photos.py` 自检，或告诉我，我一次性接图 + 构建 + 截图。
