# 05-about — 关于页全幅 + 人物

把照片按下面的文件名放进本文件夹（文件名必须一致，只有内容可变）：

| 文件名 | 画什么 | 规格 |
|---|---|---|
| `about-border-truck.jpg` | 口岸/跨境干线：友谊关或口岸排队、查验、换装 | 2000×1200（5:3）／≤350KB |
| `about-office.jpg` | （可选）河内办公室或团队合影 | 1680×1120（3:2）／≤300KB |
| `about-team-site.jpg` | （可选）现场作业：司机/协调员与设备 | 1680×1120（3:2）／≤300KB |

通用要求：横构图、白天自然光、无水印、不要车牌特写、四周留 5–8% 余量；给原图不要先压缩。

压成规格：
```bash
python scripts/optimize-images.py <原图> --as hero --out v7/05-about/<文件名去掉.jpg>
# 全幅图（2000×1200）用 --as hero；卡片图（1680×1120）用 --as card
```

放好后在此目录跑 `python scripts/check-photos.py` 自检，或告诉我，我一次性接图 + 构建 + 截图。
