# 04-projects — 代表项目（三张卡片）

把照片按下面的文件名放进本文件夹（文件名必须一致，只有内容可变）：

| 文件名 | 画什么 | 规格 |
|---|---|---|
| `project-metro-hn.jpg` | 河内地铁 1 号线：轨道物资、施工设备、站点吊装 | 1680×1120（3:2）／≤300KB |
| `project-metro-hcm.jpg` | 胡志明二号线：盾构/轨道/施工设备运输 | 1680×1120（3:2）／≤300KB |
| `project-wind.jpg` | 越南风电：叶片或塔筒在山区/沿海路段实拍 | 1680×1120（3:2）／≤300KB |
| `project-power.jpg` | （可选）电力项目：变电站设备就位 | 1680×1120（3:2）／≤300KB |

通用要求：横构图、白天自然光、无水印、不要车牌特写、四周留 5–8% 余量；给原图不要先压缩。

压成规格：
```bash
python scripts/optimize-images.py <原图> --as hero --out v7/04-projects/<文件名去掉.jpg>
# 全幅图（2000×1200）用 --as hero；卡片图（1680×1120）用 --as card
```

放好后在此目录跑 `python scripts/check-photos.py` 自检，或告诉我，我一次性接图 + 构建 + 截图。
