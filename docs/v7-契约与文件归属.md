## 3. API 契约（写死；前后端照此实现，不许各自发挥）

### 3.1 `POST /api/quote-route`
请求（与 `CalcRequest` 同形）：
```json
{ "origin": "nanning", "destination": "hanoi", "weight_kg": 20000,
  "volume_m3": null, "mode": "full_truck", "vehicle_model_id": "flatbed_low_17m5" }
```
响应：**原样透传** `CalcResult`（成功与失败两种形状都不改写字段名）。

### 3.2 `GET /api/customs/range`
查询参数：`vehicle_count`(≥1, 默认1)、`domestic_transport_rmb`、`container_count`、`container_type`、`detention_days`、`heavy_lift_tons`。
响应 A（正常）：
```json
{ "available": true,
  "china":  { "min_rmb": 2680, "max_rmb": 3280 },
  "vietnam":{ "min_vnd": 29700000, "max_vnd": 36300000 },
  "ddp":    { "min_vnd": 112000000, "max_vnd": 128000000, "rate": 3870 },
  "disclosure": "indicative_only",
  "detail_requires_lead": true }
```
响应 B（未配置系数）：
```json
{ "available": false, "note": "线上暂不提供报关费测算，请联系项目经理" }
```
算法：`cost × BORDER_MARKUP` → `×(1 ± BORDER_RANGE_PCT)` → RMB 取整到 10、VND 取整到 100000。`ddp` 需汇率（`GET /api/v1/reference/exchange-rate` → `rate`）；拿不到汇率时 `ddp` 为 `null`，**不许猜**。

### 3.3 `POST /api/lead`
```json
{ "company": "ABC 贸易", "contact": "张三", "reach": "13800000000",
  "params": { "vehicle_count": 2, "detention_days": 0 } }
```
响应 `200`：
```json
{ "leadId": "uuid", "token": "base64url", "expiresAt": "2026-11-18T14:00:00.000Z" }
```
错误：节流 → `429 {"reason":"rate_limited"}`；缺字段 → `400 {"reason":"missing_field"}`。

### 3.4 `POST /api/customs/detail`
```json
{ "leadId": "uuid", "token": "base64url",
  "params": { "vehicle_count": 2, "detention_days": 0 } }
```
响应 `200`：
```json
{ "china_side":  [ { "label_zh": "报关费", "amount": 2250, "unit": "RMB" } ],
  "vietnam_side":[ { "label_zh": "清关费", "amount": 3750000, "unit": "VND" } ],
  "china_total_rmb": 6600, "vietnam_total_vnd": 11100000,
  "notes": ["金额为对外含服务口径，非成本；正式报价以项目经理复核为准"] }
```
错误：无 token → `403 {"reason":"lead_required"}`；指纹不符/过期 → `403 {"reason":"token_mismatch"}`。
**分项数组里每个对象只允许这三个键** `label_zh|amount|unit`。

### 3.5 `POST /api/fleet-match`
```json
{ "weight_kg": 18000, "volume_m3": 40, "cargo_type": "normal",
  "items": [ { "name": "风机叶片", "length_m": 42, "width_m": 3.2, "height_m": 3.4,
               "weight_kg": 12000, "count": 1, "stackable": false } ] }
```
响应：
```json
{ "ok": true,
  "groups": [ { "model": "flatbed_low_17m5", "category": "低平板", "vehicle_count": 1,
                "reason": "超长件，需低平板", "flags": ["超长"] } ],
  "total_trucks": 1,
  "oversize": { "blocked": false, "basis": "按单件最大尺寸判定" } }
```
**丢弃**：`breakdown`、`pairs[].per_truck`、`locked`、任何金额字段。
