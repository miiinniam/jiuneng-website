## 三、拍摄/选片硬要求（瑞士编辑风对照片很挑）

1. **白天、自然光、对比度中等**；不要滤镜、不要磨皮、不要 HDR 味。
2. **横构图**，主体不要贴边，四周留 5–8% 余量（站点会裁成固定比例）。
3. **不要水印、不要车牌特写**（客户/第三方信息）；确有车牌用后期抹掉。
4. 分辨率**只许多不许少**：给原图，别先压缩。手机拍的 4MB 原图完全可以。
5. 一组图**色调要接近**（同一批项目最好），否则排版会花。
6. 若涉及客户项目，先确认可公开；拿不到授权就用「同类场景」照片，不要用别家水印图。

## 四、放好之后怎么处理

```bash
# 1) 校验：尺寸/体积/比例/缺哪张，一次性报出来
python scripts/check-photos.py

# 2) 压成站点规格（原图留在 99-raw/，不要直接上站）
python scripts/optimize-images.py public/assets/v7/01-hero/hero-main.jpg --as hero --out v7/01-hero/hero-main
python scripts/optimize-images.py public/assets/v7/03-fleet/fleet-wind-truck.jpg --as card --out v7/03-fleet/fleet-wind-truck
#    （其余同法：全幅图用 --as hero，卡片图用 --as card）

# 3) 接上站点（我来跑，改引用 + 构建 + 截图验收）
```

> `99-raw/` 只放原图，不参与构建；站点只读 `public/assets/v7/**` 下的成品。
