## 一、一句话现状

`/quote` 现在是 **「4 步向导 + 右侧一个独立聊天面板」并排跑的两套流程**：
向导自己算（点「提交测算」→ 引擎 → 页面内结果面板），AI 面板自己也算（引擎的另一套 AI → 聊天正文 + 挂在回复下方的工作台卡）。
**两者共享表单、共享引擎，但谁也不驱动谁** —— AI 不知道你表单里填了什么，向导也不知道 AI 说了什么。

## 二、现在客户实际怎么走（4 条真实路径）

### 路径 1｜纯表单（AI 不用）
```
/quat 落地 → 第1步 路线（地址搜索或地图点选，必填起终点经纬度）
           → 第2步 货物（重量必填 / 拼货必填体积 / 货类 / 可选货值 + 单件明细表）
           → 第3步 车型（整车需选车型；拼货不用；空返/装卸/三种绕行开关）
           → 点「提交测算」→ POST /api/quote/route → 页面内 q-results 结果面板
```
出处：`QuoteApp.tsx:355-437`（步骤与提交）、`RouteStep/CargoStep/VehicleStep`、`PublicResult.tsx`

### 路径 2｜表单 + 问 AI
```
先填表单（部分或全部）→ 点页头「AI 助手」→ 右滑面板 → 提问
  → POST /api/quote/ai → 引擎 /ai/chat（另一套 model + 另一套 6 个工具）
  → 聊天正文（markdown）+ 回复下方挂 q-ws 工作台卡
```
出处：`QuoteApp.tsx:329-331`（页头按钮）、`:470-481`（面板装配）、`ChatPanel.tsx:363-373`（挂卡条件）

### 路径 3｜只说一句话（设计意图里的主路径）
```
开口「从友谊关到河内，25 吨，13 米平板车」
  → 前端正则立刻抽：重量 25t / 车型 13米 / 货类 / 起终点 → patch 表单
  → 坐标靠 geocode() 补 → 表单凑齐 → autoQuote 自动跑一次引擎 → 卡片才有数字
  → 同时这句话也发给了引擎 AI，AI 自己也调工具算一遍
```
出处：`ChatPanel.tsx:157`（onHints）、`QuoteApp.tsx:261-299`（handleHints）、`:302-314`（自动测算）

> ⚠️ 路径 3 里**同一票货会被算两次**：前端自动跑 `/api/quote/route` 一次，引擎 AI 内部又跑一次 `calculate_freight_cost`。
> 两者用的不是同一套车型库/成本公式路径，结果可能不一致，而屏幕上是并排显示的。

### 路径 4｜内部版 `/quote/internal`
```
多第 4 步「成本参数」（油价/工时/过路费/杂费）+ 口令（x-quote-key）+ 模板条 + 批量 Excel + DDP
结果 = 引擎原始 QuoteResponse（含 breakdown），工作台卡里费用明细可直接改（本地 override，可撤销）
```
出处：`QuoteApp.tsx:49-52`（第4步）、`:349-353`（模板）、`:458-464`（批量）、`WorkspacePanel.tsx:152-274`（可编辑明细）

## 四、五条数据流：数字到底谁给的

| # | 数据流 | 入口 | 服务端处理 | 到屏幕上的形态 | 口径 |
|---|---|---|---|---|---|
| ① | 表单 → 引擎 | `POST /api/quote/route` | `buildPublicQuote()` 白名单重建（`quoteProxy.ts`） | `q-results` 面板 | 里程/时长/车数/车型 + `price_vnd ±10%` 区间 |
| ② | 表单 → 工作台卡 | 无网络请求 | `buildPlan(form, result, reference, scope)` 纯函数投影 | `q-ws` 卡片 | 同上（内部版才有 breakdown） |
| ③ | 一句话 → 表单 | 前端正则 | 无 | 表单被填 | `parseHints` / `parseRouteText` / `geocode()` |
| ④ | 一句话 → 引擎 AI | `POST /api/quote/ai` | **原样透传 SSE，无白名单** | 聊天正文 | 引擎自己的 prompt 与 6 个工具（见 R1） |
| ⑤ | 内部人工改价 | 无网络请求 | `overrides/extras/removed` 本地状态 | 卡片内明细 | 不覆盖引擎结果，可撤销 |

**关键结构事实**：①和②是**同一批数字的两种渲染**；④是**第三份数字**（模型的文字），且它没有被白名单约束。

## 六、现状风险与缺口（代码证据，不是意见）

| 编号 | 问题 | 代码证据 | 后果 |
|---|---|---|---|
| **R1** | **公开页 AI 的正文可能直接把成本明细说给客户** | 引擎 `ai_chat_prompt.py` 要求输出「运费明细 + 口岸费明细 + DDP 总计」的表格；工具 `_format_cost_result` 返回 `distance_cost_vnd / time_cost_vnd / fuel_cost_vnd / total_cost_vnd / cost_per_km_vnd / breakdown{13 项}`；`quoteProxy` 对 SSE **原样透传，无白名单** | 客户能在聊天里看到成本结构与每公里成本 —— 与「不暴露成本/毛利」直接冲突。工作台卡是干净的，**漏的是聊天正文** |
| **R2** | 同一批数字渲染两份 | `q-results`（页面内）+ `q-ws`（聊天面板内），文案与状态标记互不相同 | 客户看到两个「价格区」，一处说「参考价区间」一处说「区间/待核定」，容易被读成两个价 |
| **R3** | 两套 AI 能力不一致 | `/quote` 用引擎 6 工具（含「对比路线」「查汇率」）；全站悬浮助手用站内 4 工具（含「报价资料 / 条款口径」）。`Layout.tsx` 在 `/quote` 隐藏悬浮球 | 同一个客户在首页问和报价页问，得到的能力/口径不同 |
| **R4** | 没有留资，方案不落地 | `features/quote/src/` 无 `/api/lead`、无 `LeadModal`；「联系顾问」= `location.assign('/contact')` | 客户算完就走，线索库里没有这条方案；`CONTRACT §5` 的 `POST /api/quote/templates` 只存模板不存询价 |
| **R5** | 对话不持久 | `ChatPanel.tsx:71` `useState<ChatMessage[]>`，无 localStorage（站内助手有 `jn-assistant-v1`） | 刷新/切页丢对话，客户得重说一遍 |
| **R6** | 无方案版本 | `plan.ts` 只投影「当前一次」结果 | 「换 17.5 米再看看」后旧价消失，无法 A/B 比价（文档 Phase 2 未做） |
| **R7** | 中文抽取太窄 | `parseHints.ts` 只认 `吨/t/公斤/N米` + 6 个货类词；`parseRouteText` 只认「从…到…」「A→B」 | 「二十吨」「两台挖机」「凭祥口岸走友谊关」都抽不到 → 表单空着，卡片出不来 |
| **R8** | 引擎 AI 拿不到当前表单/结果 | `ChatPanel` 传 `context`，`aiChat` 放进请求体，`quoteProxy.ts:731-741` **只取 messages**，`body.context` 被丢弃、从未发给引擎 | 客户先填了表单再问「这个价含不含报关」，AI 完全不知道他填了什么，只能反问你 |
| **R9** | 前端自动测算与 AI 内部测算并行 | `QuoteApp.tsx:302-314` 自动跑 `/api/quote/route`；同一句话引擎 AI 又跑 `calculate_freight_cost` | 两套算法路径（车型库/成本公式不同源）可能给出不同车数/时长 |
