### 现状数据流（链路 1/2）

```
用户一句话
   │
   ├─ 前端：streamChat()  ──► POST /api/agent-chat  (SSE: text/tool_start/tool_done/error/done)
   │                             │
   │                             ├─ demoModel()（AGENT_CHAT_DEMO=1，本地演示，不调模型）
   │                             ├─ chatPlan()：DeepSeek 主 → Gemini 回退（CHAT_PROVIDER 可强制）
   │                             └─ runAgentChat()  ← 编排循环，MAX_ROUNDS=4
   │                                   │  systemPrompt(lang) + AGENT_TOOLS(4)
   │                                   ├─ query_route_cost ──► server/osrmQuote.ts ──► 引擎 /api/v1/route/cost
   │                                   │                        └ 白名单重建（剥 breakdown/profit/margin）
   │                                   ├─ quote_customs_range ─► server/tools/customs.ts ──► 引擎 /customs
   │                                   ├─ match_vehicles ─────► server/tools/fleet.ts ──► 引擎 /reference/fit-vehicles
   │                                   └─ lookup_service_info ─► src/agent/content.ts（站内三语，不调外部）
   │
   └─ 前端拿到 tool_done 的 name → actionsFor() 决定「下一步」按钮（报关明细 / 换车型 / 车辆匹配 / 提交询价）
```

### 现状数据流（链路 3）

```
/quote 面板
   ├─ aiChat()  ──► POST /api/quote/ai ──► quoteProxy ──► 引擎 /ai/chat（流式）
   │                                   └ 语言指令追加到最后一条 user 消息（引擎没有 lang 参数）
   └─ 本地解析：extractCoords() 抽起终点 → 表单；parseHints() 抽重量/车型 → 表单
                 plan.ts 把「表单 + /api/quote/route 结果 + reference」投影成 WsPlan
                 → WorkspacePanel 渲染（数字全部来自引擎，模型给的钱不落卡片）
```

## 三、锁定规则

1. **改之前先 `--check`，改完再 `--check`**：`changed` 必须正好是你打算改的那几个；出现「范围外改动」要先解释来源（并行 agent / 上一轮遗留），不要默认是自己。
2. **口径单点**：剥价/白名单只在 `server/osrmQuote.ts`，内部版透传只在 `server/quoteProxy.ts`。任何新流程都不许在别处再写一套。
3. **数字只来自引擎**：模型给的金额永远不落卡片、不进 SSE `tool_done.summary` 之外的正文。
4. **失败必须有终止事件**：`error + done(aborted)` 或 `FALLBACK_TEXT + done`，两条路都不许静默断流。
5. **`server/agentChat.ts` 是编排接缝**：换模型只加适配器，不动 `runAgentChat()`；换流程优先在「工具集合 + 提示词 + 前端事件消费」三处动，别重写循环。
6. **`AGENTS.md` 受保护**（改它要审批、超时即拒）：项目文档写这里或 `DEVELOPMENT.md`。

```bash
# 看清单
env -u PYTHONPATH python scripts/ai-scope.py --list

# 刷新基线（在「干净的、你认可的」状态下才执行，否则会把半成品当基线）
env -u PYTHONPATH python scripts/ai-scope.py --write

# 改动后校验
env -u PYTHONPATH python scripts/ai-scope.py --check
```
