## 风险与回滚

| 风险 | 处置 |
|---|---|
| 引擎 `/reference/fit-vehicles` 在线上不可用 | T2 失败即降级「按载重自动配」（现状 `normalizeRequest` 行为），并在 UI 标「车型为估算推荐」 |
| 预选车型与客户预期不符 | 结果页可换 + 一键重算；不隐藏车型列表 |
| AI 补丁改错字段 | 只接受白名单字段（`patch` 里的 `loadingMode` 等被忽略）+ 撤销条 |
| 拼货下线后老客户问拼车价 | 结果页保留一句「拼车请提交询价，由项目经理核算」，指向留资 |

回滚点：每个 ticket 一个 commit；P1 与 P2 之间、P2 与 P3 之间各打一次 `python scripts/ai-scope.py --write` 刷新锁定基线。
