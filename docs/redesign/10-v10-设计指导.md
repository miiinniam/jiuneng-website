## 3. 动效契约（四条铁律）

1. **CSS 里不许出现 `opacity:0` 初态。** 历史事故：`opacity:0` 入场 + IntersectionObserver 不触发（爬虫 / 截图工具 /
   rAF 节流）会让整块内容消失。初态一律由 `gsap.from()` / `fromTo()` 在动画开始那一刻写进内联样式——
   JS 没跑，内容就是常态可见。
2. **入场只加在"挂载即播放"的元素上**（Hero、PageHead）。section 级的滚动入场一律禁止，
   否则 `02` 的零装饰与上面的第 1 条会同时被破坏。
3. **滚动区只允许"按进度改浓度/尺寸"，不许 fade-in 造可见性。** 句点段（浓度）与案例照片（clip + scale）是仅有的两处；
   两者在 reduce 动效下整段不注册，元素直接是终态。
4. **只动 `transform` / `opacity` / `clip-path`。** 不许 `transition: all`、不许动 `width/height/top/left`、
   不许引第三方缓动字符串——曲线走 `tokens.css` 的 `--ease-enter` 口径（GSAP 侧用 `power3.out` / `expo.inOut` 对应）。

**reduce 动效的实测行为**（`verify-v10-motion.py` C 段）：`clip: none`、`transform: none`、三段文字 opacity 全 1。
**无 JS 的实测行为**：所有内容可见（这是规则 1 的直接结果，不是额外兜底）。

## 4. 版式规则（v10 补充部分）

- **栅格**：全站 12 列、`--maxw: 1320px`、`--margin: clamp(20px,5vw,72px)`。首页 7 类入口是唯一一处
  用"4 列 + 3 列"混排的地方（3+4=7，两行满格）；其余段仍是 4/4/4 或 7/5 对开。
- **窄屏复位**：任何跨列规则必须在 `@media (max-width:1024px)` 里写回 `grid-column: auto`，
  否则卡片会只剩 4 格宽（v10 已踩过一次）。
- **接缝**：带上下墨线的通栏（句点段）后面紧跟的段落，外边距按 0 处理并复用那条线；
  两条平行线之间必须有内容，空洞的"夹层"不算留白。
- **段高**（1440 宽实测）：hero 730 / 7 类入口 710 / 句点段 449 / 工具条 299 / 三业务 733 / 设备 705 /
  案例 1,891 / 关于 1,251 / CTA 428 / 页脚 324，整页 7,816。
  案例段 1,891 已超"两屏"上限，但拆段要重新分配照片与文案，留待 T6 决策（见 §7）。

## 5. 新增一段的标准动作

1. 先问：这件事在 `content.ts` 里有没有**可核对的事实**？没有就不要写（`02` §1 与 `09` B8）。
2. 用 `SectionHeader`（编号 + 标题 + 引文）或 `PageHead`（子页页头），不要自己写 h2 样式。
3. 需要动效时：
   - 挂载即播 → 给元素加 `data-enter="eyebrow|title-line|lead|cta|fig|figcap|stat-row"`，页面里调一次 `useEnter(ref)`；
   - 滚动进度 → 给 `<figure>` 加 `data-moment="expand"`，调 `useMomentExpand()`；**每页只放一处**；
   - 其他一律不加。
4. 图片：`aspect-ratio` 必须写死、非首屏 `loading="lazy" decoding="async"`、hero 用 `eager + fetchPriority="high"`，
   同一张图不许在两处出现（`AGENTS.md` 已记）。
5. 跑 §8 的验收，四条全绿再交付。

### 6.2 刻意不采纳

| 规则 | 不采纳的原因 |
|---|---|
| 硬规则 1「图下不许写说明」 | 12px 图注是瑞士编辑风的结构件（`02` §1.3）。删掉后照片变成无出处的装饰，等于自毁可信度 |
| 硬规则 3「每段正好 1–2 屏，hero 独占首屏」 | 本站首屏是"文 + 图 + 数据行"的三段式；要做到严格一屏一段，需重排全页并补内容，是另一个版本（T6） |
| 硬规则 5「链接卡上抬 2px、照片 hover 放大 1.02」 | 与 `02` §1.2「零装饰、悬停不位移」直接对撞；`07` 也已论证"照片索引里缩放会把注意力从内容移到效果" |
| 硬规则 7「每个图标都是真品牌图标」 | 本站不用图标，用编号（01–07）。编号可核对、不涉及商标 |
| shader / scene / 数字滚动 | 本站 kind = **service**，技能自己也只允许照片与字体型 moment |
| 词级切分（中文逐词） | 中文无词边界，切分会落在词中间；句点段按语义块切 |

### 6.3 react-bits 为什么一个组件都没进项目

逐条看过注册表（1,278 条 = 215 个组件 × 4 种方言）后，能对上的与对不上的：

| 候选 | 否决原因 |
|---|---|
| `ScrollExpand`（7.9KB，最接近"可用的 moment"） | 它的设计语言是**圆角 24px + scrim 压暗 + 压在图上的标题 + scroll hint**，四条全部违反 `02`：无圆角、照片不叠渐变、图上不压字。改到合规等于重写，还不如用已装的 GSAP 自己写 40 行（v10 就是这么做的） |
| `LogoLoop`（40.7KB） | 为"客户 logo 墙"设计的，本站没有客户 logo；为一条文字走马灯引 40KB 不划算 |
| `CountUp` / `Counter` | 技能自身规定计数只用于 tech 站；本站数据（CN-VN / 3 / 2024）也不是需要"增长感"的数字 |
| `Stepper` | 依赖 `@hugeicons/*` 两包，且本站线路工具是单屏表单，没有多步流程可指示 |
| `SplitText` / `BlurText` / 各种 cursor、background、shader | 装饰性效果，与"零装饰"和中文排版冲突 |

结论：**react-bits 是"效果库"，本站需要的是"编辑设计"**。它的价值留在按需取用（6.4），不是整包引入。

### 6.4 真要取一个 react-bits 组件时怎么做

不要 `npx shadcn init` —— 本项目不是 shadcn 工程（无 `components.json`、无 Tailwind 工具类体系），
init 会改 `tsconfig`/`vite.config` 并塞一份 `globals.css`。

按单组件取源，然后**过一遍品牌适配**：

```bash
# 1) 取源码（只取 TS + CSS 方言；TW 方言本仓库不用）
curl -sS https://reactbits.dev/r/<Name>-TS-CSS.json -o /tmp/rb.json
node -e "const j=require('/tmp/rb.json');for(const f of j.files){console.log('--',f.path);console.log(f.content)}" > /tmp/rb.txt

# 2) 落盘到 src/site/vendor/react-bits/<Name>.tsx + .css（vendor 目录，别放 node_modules）
# 3) 适配清单（缺一条就别合）：
#    - 圆角：>2px 一律改 0
#    - 颜色：全部换 tokens.css 变量，不许留 #hex
#    - 阴影/渐变/scrim：删
#    - 图上压字：改成图外 figcaption
#    - 初始 opacity:0：改成 JS 设初态，或 ensure 无 JS 时可见
#    - 动效：包在 gsap.matchMedia('(prefers-reduced-motion: no-preference)') 里
# 4) 跑 §8 全部验收
```

```bash

npm run lint                                  # tsc --noEmit，必须 0 错

env -u PYTHONPATH python scripts/verify-v8.py --url http://127.0.0.1:3300/projects --widths 390 1440

```

`verify-v10-motion.py` 断言的是**会失败的东西**（读真实计算样式，不看截图）：

| 段 | 断言 | v10 实测 |
|---|---|---|
| A 入场 | 加载 450ms 时照片 `clip-path` 是被裁的、标题行有非 0 位移；2.6s 后归位 | `inset(0% 0% 0% 76.94%)` → `inset(0%)`；`translateY 1.11px` → `0` |
| B 句点段 | scrub 区间 45% 处三段浓度递增且都在 0.28–1 之间；滚过全 1 | `[0.78, 0.58, 0.38]` → `[1,1,1]` |
| C reduce | 全程无 clip、无位移、文字全实色 | `none / none / [1,1,1]` |
| D moment | 区间中点照片处于 0<inset<7% 且 scale>1；结束满格 | `inset(3.49%)`、`scale 1.0349` → `inset(0%)`、`1` |

> ⚠️ `verify-v8.py` 启动 Chrome 时带 `--force-prefers-reduced-motion`，所以它拍到的截图里**看不到入场动画的中间态**——
> 这是故意的，用来检查"内容在 reduce 下没有消失"。动效是否存在只能由 `verify-v10-motion.py` 证明。

**v10 实测页高**：首页 1440 = 7,816 / 390 = 12,221；`/projects` 1440 = 9,327；`/services` 1440 = 5,894。
