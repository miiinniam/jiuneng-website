## 1. 采纳并已落地（5 项）

| 规则 | 原状 | 现在 | 为什么采纳 |
|---|---|---|---|
| B7「never ship browser default curve」，颜色过渡也不许用 `ease` | 13 处颜色过渡用 `ease` | 全部改成 `var(--ease-enter)`（200ms） | 一次改一处令牌，成本近零；与 `MASTER` 的「enter 曲线」口径一致 |
| B1「no orphaned words」 | 只有 `.lines li` 等少数块有 `text-wrap: pretty` | `p/li/dd/dt/figcaption/h1/h2/h3/.micro` 统一 `pretty` | 中文长句末行只剩一个字是真实观感问题 |
| B11「tagline reveal section（mandatory）」 | 无 | 首页新增 `.tagline` 句点段（分类入口之后、工具条之前），3 行大字 | 补一个"我们怎么做事"的记忆点，成本低 |
| B11 的逐块显色 | — | 每块 70ms 递进（总 ≤420ms），`opacity .34 → 1`，只动 opacity | 见 §2「偏离」——不用 word-by-word 0→1 |
| B9/B10 触屏目标 | 移动菜单项 ~33px | `.jn-mobile a{min-height:44px}` | 一列链接点错率高 |

验收：`verify-v8.py`（390/1440 全绿，页高 12,145 / 7,718）、`verify-motion.py`（A/B/C 三段全绿）。

## 2. 刻意不采纳（6 项，含理由）

| 规则 | 不采纳的原因 |
|---|---|
| B1「Never use Inter」→ 建议 Geist/Manrope | 站点是中文为主，Geist/Manrope 都没有 CJK 字形；换掉后中文会掉回系统字体，字重与字距全乱。Inter 只承担拉丁与数字。 |
| B1「Never use italic」 | 站点本来就无斜体，无需动作。 |
| B4「Never apply a border to only one side of a card」 | 本站的 `border-top` 是**排版细线**（图注、清单行），不是卡片描边；按此改会把瑞士编辑风的结构线全删掉。 |
| B5 Hero 标题用渐变文字 | 违反品牌锁定（无渐变）与 `02-视觉规范`；且 `MASTER.md` 明确禁止渐变背景/文字。 |
| B7 导航「浮起 + 背景模糊」、移动菜单改全高面板 + 逐项 60ms stagger | 属于 chrome 级重做（顶栏、汉堡、移动菜单三处联动），不是一次审校能安全落地的量；已列入 §4 待办 T4。 |
| B7 滚动进场（section 32px 上浮 + 600–800ms 淡入） | **本站硬约束**：装饰性入场会让内容在爬虫/截图/rAF 节流下消失（`AGENTS.md` 已记事故）。句点段因此改成「中性色→实色」而不是 0→1。 |
| B11「每词独立 IntersectionObserver」 | 中文没有词边界，逐词切分会切在词中间；改为按语义行/短语切块。 |

## 3. 已满足、无需动作（5 项）

- **B10**：skip link（`.jn-skip`）、favicon、`<title>`/meta/`og:image`、alt 全覆盖、语义标签（`nav/main/section/figure`）、390 无横向溢出 —— 均有脚本或既有实现兜底。
- **B9**：hover/active/focus 三态齐（v9.1 补的按压与 focus ring）；导航当前页有 `is-active`（`TopBar.tsx` 按 `pathname` 判定）。
- **B2/B3**：间距与圆角本来就是 8 倍数 / ≤2px，不需要改成 Tailwind 数值表。
- **B8 不发明事实**：全部文案只用可核对的业务事实，客户名/数据不编。
- **CLS**：所有图位都有 `aspect-ratio`，图片加载不推布局。
