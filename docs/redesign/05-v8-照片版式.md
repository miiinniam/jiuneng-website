## 3. 选片时剔掉的（有据可查，别再用）

- `web-nacelle-01` —— 左侧吊车车体印着第三方吊装公司名 `ANH DƯƠNG` + 车牌，按素材清单规则不上对客页。
- `rail-07-hanoi-station-excavation` —— 画面上半是河内街边店铺招牌（GERME / BÉP GAS / UDIC），工程感被商业招牌稀释。
- `border-05` / `border-08` —— 前者实际只是林荫路（货车很小），后者路边有大幅红酒广告牌；都不适合进照片带。
- 夜景类（`blade-03`、`real-01-rotary-rig-night`、`real-04-floating-crane-night`）—— 浅色骨架下会把亮度带压到阈值以下。

## 4. 事实口径（改图时别踩）

- `rail-06` 是河内 **3 号线**（Nhổn–河内站）在建高架，`rail-08` 是胡志明 **滨城站**；图注只能写「河内城市轨道高架在建 / 胡志明市地铁站施工 · 资料图」，不得写成 1 号线 / 2 号线。
- 车型名按照片改过：`风机叶片举升车` → **`叶片运输车组`**，`配套运输资源` → **`多轴低平板 / 轴线车`**。照片里没有举升状态，别把标题写回去。
- CC BY / CC BY-SA 图**必须**带 `credit`；新增网络图先读对应目录的 `manifest.md` 取作者与许可。

## 5. 验收

```bash
npm run lint && npm run build
NODE_ENV=production PORT=3300 node dist/server.cjs        # pty 后台，必须带 NODE_ENV
env -u PYTHONPATH python scripts/verify-v8.py --shot-dir <目录>
env -u PYTHONPATH python scripts/verify-v8.py --url http://localhost:3300/about --widths 390 1440
```

`verify-v8.py` 的断言（`02-视觉规范` §8）：横向溢出 = 0、圆角 >2px 元素 = 0、`box-shadow` ≤ 2、同页字重 ≤ 3、颜色 ≤ 6，并同时输出三档宽的整页长图。

⚠️ **不要用 `chrome --window-size=1440,20000 --screenshot` 截长图**：视口高度会喂给 `vh`，页面被拉成 2 万像素、布局失真。长图只能走 CDP 的 `captureBeyondViewport`（脚本已封装）。
