## 3. 图片管线

脚本 `scripts/build-photo-v9.py`（一张表，换图只改 src 一列）：

- 源图白名单：`SLOTS` / `VIDEOS` 的 src 一律写 `优质素材/<文件名>`；`scripts/check-photo-coverage.py` 断言「来源越界 = 0」且「34 图 + 3 视频零剩余」
- 主图：`public/assets/v9/<cat>/main.jpg`，1200×800（3:2），≤240KB
- 缩略图：`public/assets/v9/<cat>/t-NN.jpg`，640×480（4:3），≤120KB
- 视频 poster：`public/assets/v9/video/<name>.jpg`，1280×720，≤120KB
- 视频：`public/assets/v9/video/<name>.mp4`，h264 CRF31、1152×648、`-an`、faststart，实测 713KB / 814KB / 1333KB（原始共 16MB）
- 源图只读，产物只写 `public/assets/v9/`；`vite.config.ts` 的 `exclude-raw-photo-library` 继续保证素材库不进 `dist/`

命名用内容名而非 md5（`loading-drill-rig` / `floating-crane-night` / `port-crane-day`），素材库原件不改名。

## 4. 事实与合规口径

1. **地点不得张冠李戴**：`rail-01` 马德里地铁 11 号线盾构、`rail-02` 哥本哈根 Cityringen 始发井，图注必须写地点 + 「资料图」；`rail-06` 是河内 Nhổn–河内站线（3 号线）、`rail-07` 河内车站工地、`rail-08` 胡志明滨城站。
2. **署名义务**：CC BY / CC BY-SA 的 rail-01/02/06/08（rail-07 为 CC0 无义务）图注右侧带「作者 / Wikimedia Commons / 许可」；玖一 PPT 与自有实拍不署名。
3. **第三方涂装**：`web-nacelle-01` 有吊装公司「ANH DƯƠNG」车体、`web-tower-03` 吊车有「THÀNH AN」→ 只做小图，不做主图、不做正文特写；文案不出现这两家名。`web-tower-02` 里的 ZOOMLION（吊车厂牌）与「中材叶片」属设备厂标，可保留。
4. **暗图只进缩略图格**：`rail-01`（隧道内 104/255）、`real-01-rotary-rig-night`、`real-04-transformer-floating-crane-night`、`web-blade-03`（傍晚）不得做满幅/主图——浅色骨架下 200px 带亮度会跌破 120。
5. 车型/项目名与照片一致：叶片类写「叶片运输车组」，不写「举升车」；机舱那张不写「机舱运输」，写「机舱吊装上车」。

## 5. 验收

```bash
npm run lint && npm run build
env -u PYTHONPATH python scripts/check-photo-coverage.py     # 34 张 + 3 视频全部被 content.ts 引用
NODE_ENV=production PORT=3300 node dist/server.cjs           # pty 后台
env -u PYTHONPATH python scripts/verify-v8.py --shot-dir <dir>                        # 390/768/1440
env -u PYTHONPATH python scripts/verify-v8.py --url http://localhost:3300/projects --widths 390 1440
```

- 覆盖断言：34 个 `<img>` src + 3 个 `<video>` src 在 `content.ts` 里各出现 ≥1 次；缺一个即 `exit 1`。
- 视觉断言：横向溢出 = 0、圆角 >2px = 0、`box-shadow` ≤ 2、同页字重 ≤ 3、颜色 ≤ 6。
- 亮度：除照片带外任一带 <120/255 即回归；暗图必须仍在小格子里（不放大）。
- 页高：`/projects` 1440 宽**实测 9,320px**（390 宽 12,504px）；首页 7,173px、关于页 4,959px。超过 10k 就压缩缩略图行。
- 实测结果（2026-11-19）：三档断言全绿（横向溢出 0 / 圆角>2px 0 / shadow≤2 / 字重≤3 / 颜色≤6），视频三块首帧正常，7 类入口 4+3 排列正常。
